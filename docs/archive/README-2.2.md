# SANZARU — พันธสัญญาสามวานร

Three Wise Monkeys · Learning edition 2.2.0

เกมปาร์ตี้บนเว็บสำหรับผู้เล่น **3 คน / 3 หน้าจอ** ร่วมมือปิดผนึกบอสด้วยวงจรเวทและท่ามือ
ไม่มีใครถือความจริงทั้งหมด จึงต้องเชื่อมสิ่งที่รู้ผ่านมิซารุ ใช้กล้องหน้าคอมพิวเตอร์โดยไม่ต้องมีอุปกรณ์เสริม

| คิคาซารุ — Kikazaru — 聞か猿 | เห็นตราและร่ายวงจร รับเฉพาะข้อความ ส่งข้อความหรือเสียงให้มิซารุได้ | `caster` |
| อิวาซารุ — Iwazaru — 言わ猿 | อ่านตำรา รับข้อความ/เสียงได้ แต่ตอบด้วยแผ่นสัญลักษณ์เท่านั้น | `scribe` |

การตีความเชิงปรัชญาและรายละเอียดสิ่งที่เปลี่ยนอยู่ใน [DESIGN-SANZARU.md](DESIGN-SANZARU.md)
หน้าแรกเป็นประตูสู่เรื่องราวและกิจกรรม กด **เข้าร่วมพิธี** เพื่อเล่นเกมที่ `/play`
อ่านรายละเอียดส่วนใหม่ใน [LEARNING-EDITION.md](LEARNING-EDITION.md)
และโครงนำเสนอ 7 นาทีใน [PITCH-TH.md](public/learning/PITCH-TH.md)

รุ่นนี้มีหน้า `/chronicle` สำหรับประวัติและปรัชญา, `/lab` สำหรับกิจกรรมและบันทึก,
และ `/workshop` สำหรับสร้างแผนกิจกรรม 20/30/45 นาที พร้อมดาวน์โหลด
บันทึกการเรียนรู้เก็บเฉพาะเบราว์เซอร์นี้ ไม่ถูกส่งให้อาจารย์หรือทีมอัตโนมัติ

## ใช้โมเดล .pt ของคุณ

รุ่น 2.2 เพิ่มตัวเลือกโมเดล custom สำหรับคนร่าย รองรับ Ultralytics YOLO detect/classify
วางไฟล์ที่ `ai-server/models/best.pt`, ตั้ง `ai-server/model-config.json`, เปิด Python API
แล้วเลือก **โมเดล .pt ของฉัน** ในหน้า `/play` อ่านคำสั่งครบใน [CUSTOM-MODEL-TH.md](CUSTOM-MODEL-TH.md)

โหมดเดิมยังรันได้โดยไม่ต้องติดตั้ง Python ชุด AI เพิ่ม
โหมด custom ส่งภาพไปยัง Python API ที่ผู้เล่นเลือก; MediaPipe ยังติดตามปลายนิ้วบนเครื่อง
ไม่มี best.pt ของผู้ใช้รวมอยู่ใน ZIP เพราะยังไม่ได้รับไฟล์โมเดลจริง

## เริ่มรันบนเครื่อง

ใช้ Node.js 24 (ทดสอบด้วย 24.19.0) และ pnpm ตามเวอร์ชันใน `package.json`
แตก ZIP แล้วเปิด terminal ในโฟลเดอร์ `portal-panic-source`:

```sh
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm setup:local
pnpm start
```

เปิด **http://localhost:8787** และเปิด terminal ค้างไว้ขณะเล่น
`setup:local` จะ build และสร้างตารางฐานข้อมูลในเครื่อง ทำซ้ำได้โดยไม่ลบห้องเดิม
ไม่ต้องล็อกอิน Cloudflare ไม่ต้องใส่ API key และไม่มีคำสั่ง deploy ในขั้นตอนนี้
ติดตั้งครั้งแรกต้องใช้อินเทอร์เน็ตเพื่อดาวน์โหลด dependencies

โค้ดเซิร์ฟเวอร์เดิมใช้ API ของ D1/R2 ชุดนี้จึงใช้ Wrangler/Miniflare จำลองทั้งสองอย่าง
**ในเครื่องเท่านั้น** เก็บข้อมูลไว้ใน `.wrangler/state` โดยไม่สร้าง Worker บนบัญชีออนไลน์
ไฟล์ AI, WASM และภาพประกอบรวมมาใน `public/` แล้ว

## วิธีเล่น

1. คนแรกตั้งชื่อ เลือกบทบาท แล้วกด **สร้างห้อง 3 คน** ส่งรหัสห้องให้เพื่อนอีก 2 คน
2. เพื่อนเปิดเว็บบนเซิร์ฟเวอร์เดียวกัน กรอกรหัสห้อง และเข้าร่วม ระบบเลือกบทบาทที่ยังว่างให้ได้
3. **คิคาซารุ** เปิดกล้องและอนุญาตการใช้งาน หรือเลือกเมาส์เพื่อทดลองกติกา
4. ทุกคนกดพร้อม เจ้าของห้องกดเริ่ม เกมนับถอยหลัง 3 วินาที
5. คิคาซารุบอกรูปร่าง สี และจำนวนวงแหวนของตราบนเงาอคติให้ **มิซารุ**
6. มิซารุส่งคำใบ้ให้ **อิวาซารุ** ค้นสูตร แล้วอิวาซารุกดจุด 1–9 ตามลำดับ เลือกท่ามือ และกดส่งแผ่นสัญลักษณ์
7. มิซารุอ่านแผ่นสัญลักษณ์และพิมพ์เล่าต่อให้คิคาซารุ คิคาซารุชูนิ้วชี้ค้างที่จุดเริ่ม แล้วลากผ่านจุดตามลำดับ
   จากนั้นทำท่าปิดผนึกค้างประมาณ 0.9 วินาที
8. ปิดให้ครบ **5 ผนึกภายใน 4 นาที** วงจรหรือท่ามือผิดเสียสายใยความเข้าใจ 20% ครั้งที่ 5 จะแพ้

ท่าปิดผนึกมี 4 ท่า: แบมือ กำมือ ชูสองนิ้ว และยกนิ้วโป้ง สูตรสุ่มใหม่แต่ละรอบ
ช่องคุยแยกเป็นคิคาซารุ↔มิซารุ และอิวาซารุ↔มิซารุ ไม่มีช่องคุยข้ามฝั่ง
คิคาซารุส่งเสียงให้มิซารุได้ แต่ฟังเสียงตัวเองย้อนหลังไม่ได้
มิซารุส่งเสียงให้อิวาซารุได้ และฟังก่อนส่งได้ อิวาซารุไม่มีปุ่มไมค์หรือช่องพิมพ์
อัดเสียงครั้งละไม่เกิน 10 วินาที เป็นคลิปเสียง ไม่ใช่สายสนทนาสด
เซิร์ฟเวอร์ตรวจพันธสัญญาทั้ง API ข้อความ แผ่นสัญลักษณ์ อัปโหลดเสียง และดาวน์โหลดเสียง

ระหว่างเกมพักได้ทั้งตี้ ถ้าเพื่อนขาดการเชื่อมต่อประมาณ 12 วินาทีเกมจะพักให้
เมื่อกลับมาครบจะนับถอยหลังต่อ เจ้าของห้องเริ่มรอบใหม่ได้หลังชนะ แพ้ หรือพักเกม
ในห้องเตรียมตัว ปุ่ม **เปลี่ยนมุมมองทั้งสามตน** จะวนบทบาทและยกเลิกสถานะพร้อมของทุกคน
เจ้าของห้องออกจะปิดห้อง ผู้เล่นอื่นออกจะพาทีมกลับห้องเตรียมตัว ห้องหมดอายุหลังสร้าง 2 ชั่วโมง

## ทดลองหลายผู้เล่นและเล่นข้ามเครื่อง

- ทดลองบนคอมเครื่องเดียว: ใช้ 3 เบราว์เซอร์/โปรไฟล์แยกกัน เปิด URL เดียวกัน
  เลือกเมาส์ในฝั่งคนร่ายเพื่อทดลองกติกาก่อน ใช้โปรไฟล์แยกจะไม่ชน session
- เล่นกับเพื่อนคนละเครื่อง: ทุกเครื่องต้องเข้าถึง **เซิร์ฟเวอร์เดียวกัน**
  ฐานข้อมูลที่รันแยกคนละเครื่องจะไม่แชร์ห้องกัน
- URL `localhost` ใช้ได้เฉพาะเครื่องที่เปิดเซิร์ฟเวอร์ ส่งให้เพื่อนต่างเครื่องเข้าไม่ได้
- กล้องและไมค์ต้องใช้ **HTTPS** หรือ `localhost` ที่เบราว์เซอร์ยอมรับ
  การเปิดผ่าน IP ใน LAN แบบ HTTP อาจเล่นด้วยเมาส์ได้ แต่กล้องและไมค์จะถูกบล็อก
- การเปิดให้คนภายนอกเข้าใช้จริงต้องมีโฮสต์/HTTPS เพิ่มเติม การส่งมอบครั้งนี้ไม่ได้ deploy ใหม่

## แก้ไขและทดสอบ

```sh
pnpm dev          # โหมดแก้ไข http://localhost:5173
pnpm typecheck
pnpm test
pnpm build        # สร้างผลลัพธ์ใหม่หลังแก้โค้ด
pnpm db:local     # ใช้เมื่อมี migration เพิ่ม หลัง build
pnpm start        # รันผลลัพธ์ที่ build แล้ว
```

หากฐานข้อมูลใน dev ยังไม่มีตาราง ใช้ `pnpm setup:local` ก่อน
อย่าเปิด `dev` และ `start` พร้อมกันขณะตรวจฐานข้อมูลเดียวกัน
ตรวจเซิร์ฟเวอร์ที่เปิดอยู่ได้โดยเปิดอีก terminal แล้วรัน `pnpm test:local`
ดูขอบเขตการทดสอบและตารางทดลองกล้อง 10 ครั้งใน [TESTING.md](TESTING.md)

## ข้อจำกัดที่ควรรู้ก่อนนำเสนอ

- ความแม่นยำขึ้นกับแสง ระยะกล้อง การบังนิ้ว และประสิทธิภาพเครื่อง ต้องทดลองกับกล้องจริง
  ผล automated tests ไม่ใช่ผลความแม่นยำ 8/10
- เหมาะกับเดโมและโปรเจกต์ห้องเรียน ยังไม่มีบัญชี, matchmaking, billing
  หรือมาตรการป้องกันการโกงระดับเกมแข่งขัน
- โหมดเมาส์ใช้ทดลองกติกาหรือช่วยเมื่อกล้องอ่านไม่ออก ไม่ได้นับเป็นการจำแนกภาพด้วย AI
- ผลการอ่านท่ามือส่งจาก frontend จึงไม่ใช่การยืนยันการเคลื่อนไหวที่กันการปลอมแปลงได้

## สิ่งที่รวมใน ZIP

โค้ด frontend/backend, ภาพเกม, โมเดล AI และ WASM, SQL migrations,
ไฟล์ตั้งค่า, lockfile, tests และคู่มือนี้
ไม่รวม `node_modules`, ไฟล์ build, ห้อง/เสียงผู้เล่นจากการทดสอบ, รหัสผ่าน หรือ token
ใช้คำสั่งติดตั้งด้านบนเพื่อสร้าง dependencies และ build บนเครื่องของคุณ
คง license ของส่วนประกอบภายนอกไว้ในชุดโค้ด

## ผลตรวจชุดส่งมอบ

- TypeScript: ผ่าน
- ชุดทดสอบกติกาและ API: ผ่าน รวมการสื่อสารตามสามพันธสัญญา
- Production build: ผ่าน
- ZIP: ตรวจ CRC และ manifest ครบก่อนส่ง
- ยังไม่ได้ทดสอบหน้าจอด้วยเบราว์เซอร์จริง หรือวัดความแม่นยำกับกล้อง/ไมค์จริงในรอบแก้ไขนี้

ค่าเริ่มต้นใช้ MediaPipe มีส่วนเชื่อม Ultralytics .pt ผ่าน Python เป็นตัวเลือก
ไม่มี weights ของผู้ใช้หรือ Roboflow API key ฝังอยู่ในโปรเจกต์
ชื่อโฟลเดอร์และรหัสบทบาทเดิมยังคงไว้เพื่อให้อ่านเทียบกับโค้ดรุ่นก่อนง่าย
