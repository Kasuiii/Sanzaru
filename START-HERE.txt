SANZARU — Hand to Heart / ONNX Runtime Web

โมเดล YOLO26n ASL ของทีมแปลงเป็น ONNX และติดตั้งในโปรเจกต์แล้ว
A–Z + nothing (ไม่ส่งคำตอบ), input 384×384 (มี 640×640 ให้เลือก), ไม่ต้องเปิด Python ขณะเล่น

รันจาก source folder นี้:
1. ติดตั้ง Node.js 22.13+ และ pnpm ตาม package.json
2. pnpm install --frozen-lockfile
3. pnpm setup:local
4. pnpm start
5. เปิด http://localhost:8787/lab แล้วเชื่อมโมเดลและเปิดกล้อง

Deploy จาก source: อ่าน DEPLOY-CLOUDFLARE-TH.md
Deploy จาก ZIP ที่ build แล้ว: แตก release/sanzaru-onnx-performance.zip (ไฟล์ในเครื่อง ไม่ได้รวมใน Git)
แล้วอ่าน DEPLOY-THIS-BUNDLE-TH.md ภายใน

ต้องใส่ D1 database_id และ R2 bucket ของบัญชีคุณก่อน deploy
อัปเดตเว็บเดิมด้วย config เดิม ตาม PERFORMANCE-ASL-TH.md

MODEL-REPORT-TH.md: รุ่นโมเดล/hash/ผลทดสอบจริงและข้อจำกัด
ONNX-RUNTIME-WEB-TH.md: คำอธิบายโค้ดและลำดับการประมวลผล
ASL-SETUP-TH.md: วิธี export ใหม่เมื่อเปลี่ยนโมเดล
TESTING.md: ผลทดสอบระบบทั้งหมด
