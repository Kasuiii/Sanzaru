# Portal Panic 1.0 — Source handoff

ชุดส่งมอบวันที่ 14 ตุลาคม 2026 สำหรับนำไปรันและแก้ไขเอง ไม่มีการ deploy เพิ่มในรอบนี้

## สิ่งที่เสร็จแล้ว

- เกมออนไลน์ 3 บทบาท คนร่าย/คนอ่านตำรา/คนกลาง พร้อมข้อมูลและช่องคุยแยกกัน
- ลากวงจรด้วยปลายนิ้วและปิดผนึกด้วยท่ามือ มีเมาส์/คีย์บอร์ดสำหรับทดลองกติกา
- สุ่มสูตร 5 ผนึกใน 4 นาที ระบบคะแนน เสถียรภาพ พักเกม กลับเข้าห้อง และเล่นรอบใหม่
- เจ้าของห้องสลับบทบาททั้งทีมได้แม้ครบ 3 คน โดยทุกคนต้องกดพร้อมใหม่
- แก้คิวข้อความติดค้างจาก rate limit และจำกัดชุดคำสั่งให้ตรงกับเซิร์ฟเวอร์
- แก้คำอธิบายท่ามือให้ตรงกับโหมดวงจรเวท
- แชตเลื่อนเฉพาะในช่องข้อความและป้องกันการเปิดไมค์ซ้ำระหว่างรอสิทธิ์
- เพิ่ม setup ฐานข้อมูลในเครื่อง, คำสั่งทดสอบ และคู่มือภาษาไทย

## ผลการตรวจ

- TypeScript: ผ่าน
- Production build: ผ่าน
- ชุดทดสอบกติกา/API ทั้งโหมด 3 คนและโหมดเดิม: ผ่าน
- Migration ฐานข้อมูลใหม่และเรียกซ้ำ: ผ่าน
- เซิร์ฟเวอร์ local จาก build จริง: หน้าเว็บ/โมเดล/ภาพ, ห้อง 3 คน,
  สลับบทบาท, ซ่อนข้อมูล, ร่ายหนึ่งผนึก, แชต และที่เก็บ/สิทธิ์เสียง ผ่าน
- ทดสอบด้วย Node.js v24.19.0 และ dependencies ตาม lockfile ที่ติดตั้งในสภาพแวดล้อมนี้
- ยังไม่ได้ทดสอบติดตั้ง dependencies ใหม่บน Windows/macOS, ใช้กล้อง/ไมค์จริง
  หรือวัดความแม่นยำ 10 รอบ ให้บันทึกผลจริงใน TESTING.md

เสียงในการทดสอบอัตโนมัติเป็นข้อมูลจำลองเพื่อทดสอบที่เก็บและสิทธิ์
ไม่ใช่การยืนยันคุณภาพการอัด/เล่นเสียงจริง
